# Downloady Telegram Media Bot

Телеграм-бот, который принимает ссылку на пост из соцсетей (Instagram, Facebook, Pinterest и др.) и возвращает медиа (видео/изображения). Бот использует `yt-dlp` для извлечения прямых ссылок и отправляет их в Телеграм.

## Возможности
- Поддержка множества площадок за счёт `yt-dlp` (Instagram, Facebook, Pinterest, TikTok, Twitter/X и т.д.)
- Принимает обычное текстовое сообщение с URL, извлекает и отправляет медиа-файлы
- Отправляет альбом (media group), если найдено 2–10 элементов
- Webhook для Railway и polling для локальной разработки
- Простой health-check `/` на веб-сервере

## Запуск локально (polling)
1. Установить зависимости:
   - Python 3.10+
   - `pip install -r requirements.txt`
2. Создать `.env` на основе `.env.example` и прописать `TELEGRAM_TOKEN`.
3. Запуск:
   - `python -m app.bot` или `make run`
   - По умолчанию запустится в режиме polling (если не установлен `WEBHOOK_BASE`).

## Деплой на Railway (webhook)
1. Создать сервис на Railway и деплойнуть этот репозиторий.
2. В переменных окружения Railway указать:
   - `TELEGRAM_TOKEN` — токен бота
   - `WEBHOOK_BASE` — внешняя HTTPS-ссылка сервиса, например `https://<your-service>.up.railway.app`
   - `SECRET_TOKEN` — любая строка 16-32+ символов (для валидации вебхука Телеграма)
   - `PORT` — не задавайте вручную, Railway подставит автоматически
3. В Procfile уже прописан процесс: `web: python -m app.bot`

После старта, бот автоматически установит webhook на `<WEBHOOK_BASE>/webhook` и начнёт получать обновления.

## Ограничения и заметки
- Приватный контент и сторис с ограничениями могут не работать без авторизации/cookies (в рамках MVP поддерживаем только публичные ссылки).
- Telegram может отклонять слишком большие файлы; в этом случае бот отправит прямую ссылку для скачивания.
- В редких случаях конкретные посты могут иметь нестандартную разметку — бот постарается подобрать лучший формат (прогрессивный MP4/WebM) или вернёт прямую ссылку.

## Структура
- `app/bot.py` — входная точка бота, хендлеры, режимы webhook/polling
- `app/downloader.py` — извлечение прямых ссылок на медиа через `yt-dlp`
- `app/config.py` — чтение переменных окружения
- `requirements.txt` — зависимости
- `Procfile` — процесс для Railway
- `Makefile` — быстрые команды `install`, `run`
